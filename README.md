# Tetraphobia Neovim Config (v3.0)
This is my Neovim config.
## Requirements
- Neovim >=0.10

## Installation
Clone this repo to `$HOME/.config/nvim`

```
git clone git@github.com:tetraphobia/nvim-config.git ~/.config/nvim
```
Upon launching, you will likely be greeted by a bunch of warnings about missing dependencies.
Install the ones you want, then run `touch $HOME/.config/nvim/.nodepcheck` to disable the warnings.
